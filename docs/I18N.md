# دعم تعدد اللغات (i18n)

المتجر يدعم الآن **العربية (RTL)** و**الإنجليزية (LTR)**، مع بنية قابلة للتوسّع
لإضافة أي لغة لاحقًا. هذا الدليل يشرح المعمارية وكيفية إكمال ترجمة بقية الشاشات.

## المعمارية

- **المكتبة:** [`next-intl`](https://next-intl-docs.vercel.app/) (وضع الكوكيز — بدون
  `/en/...` في الرابط، فلا حاجة لنقل المسارات إلى مجلد `[locale]/`).
- **تحديد اللغة:** كوكي `NEXT_LOCALE`. يُقرأ على الخادم في
  [`src/i18n/request.ts`](../src/i18n/request.ts) وفي الجذر
  [`src/app/layout.tsx`](../src/app/layout.tsx) الذي يضبط `<html lang dir>`
  ويقلب الاتجاه RTL⇄LTR تلقائيًا.
- **تبديل اللغة:** [`LanguageSwitcher`](../src/components/store/LanguageSwitcher.tsx)
  يكتب الكوكي عبر server action ([`src/i18n/actions.ts`](../src/i18n/actions.ts))
  ثم `router.refresh()`.
- **ملفات النصوص:** [`messages/ar.json`](../messages/ar.json) و
  [`messages/en.json`](../messages/en.json) — نفس المفاتيح في الملفين.
- **الإعدادات:** [`src/i18n/config.ts`](../src/i18n/config.ts) — قائمة اللغات،
  الاتجاه، الأسماء. **لإضافة لغة:** أضف رمزها هنا + ملف `messages/<code>.json`.

## ترجمة نصوص الواجهة

### مكوّن عميل (`"use client"`)

```tsx
import { useTranslations } from "next-intl";

export function Foo() {
  const t = useTranslations();          // أو useTranslations("product")
  return <button>{t("product.addToCart")}</button>;
}
```

### مكوّن خادم (`async function`)

```tsx
import { getTranslations } from "next-intl/server";

export async function Foo() {
  const t = await getTranslations();
  return <h1>{t("nav.products")}</h1>;
}
```

### متغيّرات داخل النص

```json
{ "product": { "addedToCart": "تم إضافة {name} إلى السلة" } }
```
```tsx
t("product.addedToCart", { name: displayName })
```

## ترجمة محتوى قاعدة البيانات (المنتجات/التصنيفات)

الجداول تحمل عمودين لكل حقل مترجَم: عربي (`nameAr`, `descriptionAr`,
`featuresAr`) وأساسي/إنجليزي (`name`, `description`, `features`). استخدم مساعدات
[`src/lib/i18n-content.ts`](../src/lib/i18n-content.ts) لاختيار الصحيح حسب اللغة
(مع رجوع تلقائي للطرف الآخر إذا كان فارغًا):

```tsx
// مكوّن عميل
import { useLocale } from "next-intl";
import { pickText, pickList } from "@/lib/i18n-content";
const locale = useLocale() as Locale;
const name = pickText(locale, product.name, product.nameAr);

// مكوّن خادم
import { getLocale } from "next-intl/server";
const locale = (await getLocale()) as Locale;
```

> **لإضافة لغة ثالثة للمحتوى:** المساعدات في `i18n-content.ts` هي نقطة التغيير
> الوحيدة — استبدل منطق العمودين بعمود JSON اسمه `translations` مفهرس باللغة،
> وتبقى كل مواضع الاستدعاء تعمل دون تغيير.

## المتبقّي

يوجد ~2810 نص عربي عبر ~133 ملفًا (المتجر + لوحة التاجر + الأدمن). الترتيب المقترح
حسب الأولوية:

1. **شاشات المتجر** (`src/app/(store)`, `src/components/store`) — الأعلى أثرًا.
2. **صفحات الدخول** (`src/app/(auth)`).
3. **لوحة العميل** (`src/app/dashboard`, `src/components/dashboard`).
4. **الأدمن** (`src/app/admin`, `src/components/admin`) — الأكبر حجمًا.

### خطوات تحويل أي ملف

1. استخرج كل نص عربي مكتوب مباشرة إلى مفتاح في `messages/ar.json`.
2. أضف الترجمة المقابلة في `messages/en.json` بنفس المفتاح.
3. استبدل النص في الكود بـ `t("...")` (عميل: `useTranslations`، خادم:
   `getTranslations`).
4. أي اسم/وصف قادم من قاعدة البيانات: مرّره عبر `pickText` / `pickList`.
5. شغّل `npx tsc --noEmit` للتأكد من سلامة الأنواع.

### تنظيم المفاتيح

استخدم أسماء نطاقات (namespaces) واضحة: `common`, `nav`, `navbar`, `footer`,
`product`, `cart`, `auth`, ثم أضف نطاقات جديدة عند الحاجة مثل `checkout`,
`account`, `admin.orders` … إلخ. حافظ على تطابق المفاتيح بين `ar.json` و`en.json`.
